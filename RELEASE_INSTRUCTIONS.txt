RoadReady — Release Checklist
==============================

Follow these steps in order every time you want to ship a new version.
Example version used below: 1.0.1 — replace with your actual new version number.


STEP 1 — Bump the version number (two places, must match)
-----------------------------------------------------------
1. Open app/main.py
   Find: APP_VERSION = "1.0.0"
   Change to your new version, e.g.: APP_VERSION = "1.0.1"

2. Open installer/RoadReady.iss
   Find: #define MyAppVersion "1.0.0"
   Change to the same new version, e.g.: #define MyAppVersion "1.0.1"


STEP 2 — Rebuild the app
-----------------------------------------------------------
Run in a terminal from the project folder:

    .venv\Scripts\pip install -r requirements-build.txt
    .venv\Scripts\pyinstaller RoadReady.spec

This produces dist\RoadReady.exe.


STEP 3 — Rebuild the installer
-----------------------------------------------------------
Run (adjust the path if Inno Setup is installed somewhere else):

    "C:\Users\<you>\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer\RoadReady.iss

This produces installer\Output\RoadReadySetup.exe
(This Output folder is not tracked by git — that's expected.)


STEP 4 — Commit and push your code changes
-----------------------------------------------------------
    git add -A
    git commit -m "Bump version to 1.0.1"
    git push origin main


STEP 5 — Tag this release and push the tag
-----------------------------------------------------------
    git tag v1.0.1
    git push origin v1.0.1

(Use the same number as APP_VERSION, prefixed with a lowercase "v".)


STEP 6 — Create the GitHub Release
-----------------------------------------------------------
1. Go to: https://github.com/VaratisG/RoadReady/releases/new
2. Under "Choose a tag", select the tag you just pushed (e.g. v1.0.1).
3. Release title: RoadReady v1.0.1
4. Description: optional — a short list of what changed.
5. Scroll down to "Attach binaries by dropping them here or selecting them"
   and drag in: installer\Output\RoadReadySetup.exe
   (The file must be named exactly RoadReadySetup.exe.)
6. Click "Publish release".


STEP 7 — Update Supabase so the app knows about the new version
-----------------------------------------------------------
Go to your Supabase project -> SQL Editor and run:

    update app_version
    set latest_version = '1.0.1', updated_at = now()
    where id = 1;

(Replace '1.0.1' with your new version number.)


STEP 8 — Verify the download link works
-----------------------------------------------------------
In PowerShell:

    Invoke-WebRequest -Uri "https://github.com/VaratisG/RoadReady/releases/latest/download/RoadReadySetup.exe" -OutFile "test-download.exe"
    Get-Item test-download.exe | Select-Object Name, Length

It should download a real file around 25-30 MB, not an error page.
Delete test-download.exe afterward — it was only for testing.


DONE
-----------------------------------------------------------
Anyone who already has RoadReady installed will now see an
"update available" prompt the next time they open the app.
Clicking "Ενημέρωση τώρα" downloads RoadReadySetup.exe from the URL above,
runs it, and closes the app so the install can finish.


NOTES
-----------------------------------------------------------
- The GitHub repo must stay PUBLIC for the download link to work, since the
  app downloads the file without logging in to GitHub.
- You never need to change the app's download URL again — it always points
  at "releases/latest", which automatically follows whatever release you
  publish most recently, as long as the asset is always named
  RoadReadySetup.exe.
- If something goes wrong with a release, you can delete the GitHub Release
  and re-publish it (same tag or a new one), then re-run STEP 7 if the
  version number changed.
